How to build a playlist
  1. Connect. Enter your Jellyfin server URL and an API key (Dashboard → API Keys). Users load automatically; pick the playlist Owner. Tick Remember login to keep the URL, key, and owner in this browser (untick to forget).
  2. Pick media types with the Movies / TV / Music chips. Music is its own mode: it shows albums with their tracklists, so you can stage whole albums or individual songs. Switching between Music and Videos clears the playlist (a playlist can only hold one kind).
  3. Search any term and press Enter — matching titles appear in the Results pane. Use Refine to narrow by year, rating, genre or studio.
  4. Add to the playlist by clicking on a card (it becomes ). Hover to see details. Results are disposable — keep searching and adding; the playlist on the right accumulates.
  5. Arrange the playlist rows with ↑ ↓, or sort/reorder them, and remove with ✕.
  6. Save gives the playlist a name and creates it on your Jellyfin server. The playlist itself is never stored locally — it is lost on refresh.

API keys live only in the page for this session — never commit real keys to source control.
